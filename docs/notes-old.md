S3: Stores websites static files(HTML, CSS, JavaScript, images).
CloudFront: Acts as a Content Delivery Network (CDN) to cache and deliver a website's content globally with low latency and high speeds.
Route 53: Provides a scalable Domain Name System(DNS) to route user requests to your infrastructure.
API Gateway: acts as the front door for backend requests, creating and managing REST/HTTP APIs that route traffic to computers.
Lambda: runs backend code as serverless functions in response to events(triggered by API Gateway) without requiring server management.
DynamoDB: a fast, fully managed NoSQL database used to store and retrieve application data
IAM (Identity Access Management): manages access controls and permissions of AWS services and resources.
Cognito: handles user authentication and authorization
